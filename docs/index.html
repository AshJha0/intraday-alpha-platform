intraday-alpha-platform

An institutional-style, event-driven research-to-production trading platform for equities and FX — deliberately polyglot: Python for research and reference implementations, C++ for the latency-critical path, Rust for safety-critical infrastructure, Java for the strategy/platform layer. Market data → order books → 205-feature factory → 24 alphas → validation → ML → portfolio → fail-closed risk → execution/SOR → deterministic replay → TCA, held together by cross-language golden tests.

The adversarial review of this platform found — and fixed — a generator artifact that left the consolidated equity book crossed 95% of the time and silently inflated ML information coefficients. After the fix (a shared efficient price per instrument) the crossed fraction is 0.8%, every golden file and research report was regenerated, and the alpha promotion count honestly fell from 2 to 0. What's inside

Market data foundation

Seeded synthetic equity MBO + multi-venue FX quote generator (regime-switching efficient price, clustered flow, halts/auctions, injected anomalies), raw→normalized pipeline with sequence-gap/duplicate/out-of-order QC, JSONL + IAP1 binary codecs byte-identical across languages, Parquet research datasets.

Order books

L1/L2/MBO reconstruction with FIFO queues, pinned modify semantics, marketable crossing ADDs, snapshot recovery (incl. broken-burst rule), per-venue + consolidated views, deterministic checkpoints — identical state in Python, C++, Rust and Java after every event.

Feature factory

205 registered features across price, microstructure, order flow (OFI L1–L10), liquidity, volatility, time-of-day, cross-asset, venue, regime and execution families; event-driven incremental engines in all four languages validated to 1e-9 against golden checkpoints.

Alpha library

12 equity + 12 FX flagship alphas (microprice, multi-level OFI, queue depletion, momentum/reversal, VWAP deviation, lead-lag, carry-style currency factors, regime-conditioned variants), each with a mandatory economic-rationale docstring and declared feature dependencies.

Validation framework

Event-time labels at 11 horizons (10ms–15m), walk-forward with purging + embargo, automatic leakage tests, IC/RankIC/Newey-West t/hit/decay/turnover/capacity, a persistent multiple-testing ledger, and cost/latency/regime stress — the §20 promotion gates, enforced literally.

ML & meta-labeling

Linear baselines gate the advanced models (literally — trees/MLP only run if the baseline shows OOS signal), LightGBM/XGBoost, isotonic-calibrated trade/no-trade meta-labels evaluated economically, and full reproducibility manifests (data/feature/model versions, windows, hardware) on every fit.

Portfolio construction

alpha'w − λ·w'Σw − tc(Δw) under position/gross/net/participation/turnover/ vol-target and FX currency-exposure constraints; deterministic projected-gradient production optimizer (Java) matching the Python reference to 1e-9, with a constraint-audit report.

Fail-closed risk

Fat-finger, price-band, stale-price, position/notional/gross/net, loss limits, rate throttle, duplicate-order and self-match prevention, sequence-gap gating, venue-disconnect handling and four-scope kill switches — Rust reference + Java port with byte-identical audit logs, replayable.

Execution & SOR

Market/limit/IOC/FOK, VWAP/TWAP/POV/IS parent algos, deterministic queue-position modeling for passive orders (pinned depletion rules), fees/rebates/impact, venue latency with seeded jitter, and fee-aware smart order routing — C++ reference fills reproduced exactly by Java.

Event-driven backtester

Replays every market event in event-time through book → features → alphas → portfolio → risk → execution with modeled decision/wire/venue latency, partial fills and queue position; identity-tested P&L accounting; checkpoint/restart bit-identical to uninterrupted runs.

TCA & attribution

Arrival/VWAP/TWAP benchmarks, Perold implementation-shortfall decomposition (delay/trading/opportunity — exact identity), spread/impact/timing split, post-fill adverse-selection markouts at 100ms/1s/10s, and impact regression versus participation.

Adaptive lifecycle

Models decay, so the platform measures it: pinned PSI/KS drift monitors against serialized research baselines, rolling realized-vs-research IC, drift-triggered refits on purged/embargoed windows, and an IC-gated ACTIVE→WATCH→RETIRED state machine with hysteresis that verifiably halts allocation — with live PSI, rolling-IC and lifecycle gauges monitored in paper trading.

Cross-language golden parity

The Python reference generates validated golden vectors (events, book states, codec SHA-256, features, alphas, risk decisions, fills, portfolio); C++, Rust and Java must reproduce every one. tests/harness/run_all.sh prints the parity table in one command.

Observability & deployment

Prometheus metrics (rust telemetry + 19 live Java metrics with /metrics, /health), recording + alert rules, two Grafana dashboards, structured JSONL logs, Dockerfiles + docker-compose + Kubernetes manifests, runbooks, governance and reproducibility docs, and a paper-trading mode.

Research papers

Six case studies written from the platform's own measured outputs: OFI predictability, microprice/queue dynamics in FX, cross-venue lead-lag, alpha decay vs latency economics, queue-aware execution and adverse selection, and C++ vs Rust vs Java for event-driven trading.

Performance engineering

Benchmark suite with published methodology (hardware, toolchain, boundaries, variance caveats — no isolated numbers): codec, book, replay, feature engine, alpha scoring and execution-sim stages, plus demo-scale Rust/Java replay throughput.

Quick start

git clone https://github.com/AshJha0/intraday-alpha-platform && cd intraday-alpha-platform

# generate the deterministic synthetic dataset, then the feature/label store
cd python && PYTHONPATH=src python3 -m iap.marketdata && PYTHONPATH=src python3 -m iap.features && cd ..

# run everything — builds and tests all four languages, prints the parity table
bash tests/harness/run_all.sh

# research pipelines (honest reports in research/)
PYTHONPATH=python/src python3 research/alpha_reports/run_all.py
PYTHONPATH=python/src python3 research/ml_reports/run_ml.py

# paper trading with live /metrics on :8080
cd java && ./paper.sh
