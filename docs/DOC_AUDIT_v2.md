# Documentation audit, v2.0 (2026-10-25)

Every Markdown document in the repository outside `docs/release/` and `docs/review/` (those two
directories are records of reviews and releases and are left as they are), judged against `main`
at d9a89522 on 2026-10-25, with the owner's instruction "review and rewrite documentation so that
it is correct, factual and user friendly". 229 documents.

## 1. What the audit judged against

- the v2.0 programme: plan of record (IAP_v2.0_Unified_Programme_Plan_2026-10-24, revision 3) and
  the unified specification U0 (revision 1), kept outside the repository; the evidence classes of
  U0 section 10 (independently confirmed, mechanically isolated, development-supported, exploratory,
  rejected, data-ineligible, pending) and the rule that every performance statement carries one;
- the facts on `main`: no alpha is confirmed and nothing is above *development-supported*; the H3
  and H4 intraday families are data-ineligible and D5 is ineligible on daily data; the data route is
  free sources (Stooq or Tiingo, the Wikipedia membership proxy, EDGAR, French factors, IEX HIST)
  and nothing has been ingested; the Java layer is archived at git tag `archive/java-v1.14.0` and
  its tree leaves with pull request #391; the Python, C++ and Rust engines of v1.x are unchanged;
- two frozen documents are never edited: `python/tests/spec/CONFIRMATORY_TEST_SPEC.md` (R0) and
  `research/v119/H1_ALPHA_IMPROVEMENT_SPEC.md` (E0), each hashed by a test.

For each document: the audience (operator, researcher, reviewer, newcomer, contributor), what it
claims, whether that is true on `main` today with the file or test that supports or contradicts
it, and the disposition. The dispositions: **keep** (true and useful as it stands, or a record);
**rewrite** (useful, needs correction; the correction is named); **merge into** another document;
**retire** (moved under `docs/archive/` with a one-line header saying why; never deleted). A
document pinned by a harness (`tests/harness/check_docs.py`, `check_headline_numbers.py`), by a
test, by a signed pre-registration or by a research record is kept where it is whatever its
age, because moving it breaks the pin; such a document gets a banner or a correction instead.
