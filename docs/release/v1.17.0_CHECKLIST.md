# v1.17.0 release checklist

Built from `python tools/release.py flow` (a dry run by default; `--execute` acts).

## Before
- [x] All v1.17 code PRs merged (waves 1-7, #162-#208). B7 and B8 real-data results are
      deferred to v1.17.1 by owner decision (2026-10-16).
- [x] CHANGELOG `## Unreleased` content moved under `## v1.17.0 — 2026-10-16` with the theme
      paragraph; duplicate bullets removed; version 1.17.0.
- [x] `docs/index.html`, README and ROADMAP name v1.17.0 (the publish site check needs it).
- [ ] Regenerate (CI `regenerate`), apply the bundle, review the diff; update the MVP digest
      and ledger counts in the docs if they moved; regenerate `docs/research/R7_POWER.md` if
      the ledger look count changed.

## Flow (tools/release.py)
1. [ ] `python tools/release.py prepare-regenerate --branch release/v1.17.0 --execute`
       (resets `research/experiments.json` to origin/main, drops the runner dirs, commits,
       pushes, dispatches `ci.yml -f regenerate=true -f regenerate_allow_rerun=true`).
2. [ ] `python tools/release.py apply-bundle --run-id <run> --execute`; restore any experiment
       dirs the regenerate does not recreate; commit; push.
3. [ ] The owner merges the release PR (merge commit).
4. [ ] `python tools/release.py publish --version 1.17.0 --execute`: waits for main CI and
       CodeQL, tags from the CHANGELOG, `gh release --verify-tag`, watches release.yml, pins
       the image digests (follow-up PR).

## After
- [ ] G5 post-release truth pass (site, README, SHOWCASE, ROADMAP, ledger counts, runbook
      fixes: Python 3.11 or 3.12 for `.venv-ci`, `.\` prefix in PowerShell commands), one PR
      before the release is announced.
- [ ] v1.17.1: the IEX overlap day rows, B8 real-book evaluation, B7 prereg (owner signs) and
      fresh test.
