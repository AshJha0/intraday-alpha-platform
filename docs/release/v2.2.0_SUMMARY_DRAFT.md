## (a) Three-minute summary

**What the platform is.** A research and execution platform for US equities that runs from raw
exchange messages to a cash-reconciled ledger, built to answer one question carefully: does a
systematic signal make money after costs, and how would we know? Python is the reference
implementation; C++ owns the latency path and Rust the risk engine, with golden tests holding the
three equal ([README.md](../../README.md), [REPORT.md](../REPORT.md) section 1). Every look at data is
counted in a ledger ([research/experiments.json](../../research/experiments.json)), and a hypothesis
can only be confirmed by a pre-registered, signed, single-shot test on sealed data
([GOVERNANCE.md](../GOVERNANCE.md)).

**What the evidence supports.** The engineering: deterministic replay, a fail-closed risk engine,
ledgers that reconcile to cash, three-language parity, leakage canaries, a holdout registry that
refuses unregistered reads. These are *development-supported* on fixtures, with no return claim
([REPORT.md](../REPORT.md) section 2, and the v2.0.0 notes section 7).

**What it does not support.** Any alpha. Nothing is above *development-supported*. Where a signal
predicts, it is smaller than the cost of trading it: intraday signals with a real information
coefficient net zero at 1x costs; a cost-aware taker trades in none of 480 grid cells; two-sided
quoting loses USD 5.0k to 6.9k a session (REPORT.md section 2, rows 5 to 7). This round added: an
event-driven quoter lost USD 11,201.51 against the grid quoter's 10,155.22 on its one development
session ([QUOTER_EVENT_DRIVEN_DEV.md](../../research/round1/QUOTER_EVENT_DRIVEN_DEV.md) section 5); a
500-name reversal on full-market bars was negative net of spread on its one development session
([BREADTH_BARS_20190130.md](../../research/round1/BREADTH_BARS_20190130.md)); pooled over ten sessions,
[[PENDING: pooled ten-session reversal result]]; families F1 to F3, [[PENDING: F1, F2, F3 results]];
holdout, [[PENDING: holdout outcome]].

**Why it cannot support more on free data.** A session-level power calculation shows ten sessions
detect only a net Sharpe of about 16 or more and a Sharpe near 1 needs about 1,980 sessions
([PNL_POWER_TABLE.md](../research/PNL_POWER_TABLE.md),
[ROUND0_GATES.md](../../research/round0/ROUND0_GATES.md) section 8). The free daily data failed its
survivorship test (85 % of index leavers missing), IEX withdrew its intraday captures from direct
download, and no other free source qualifies (ROUND0_GATES.md sections 1 and 6). The platform says so
rather than running studies that cannot succeed (the stop rule, PNL_POWER_TABLE.md).

**What the AI layer does.** Code computes every number and verdict; the AI layer searches the
record, structures the workflow and checks text. A research memory (BM25, file:line citations), a
state graph that stops for a person before any run, a read-only MCP server on the official SDK,
five Claude Code skills, and a number verifier that refuses any figure not found in a cited
artefact ([AI_STACK.md](../AI_STACK.md)).

**How it is measured.** Offline, with no model call (live calls are off by owner decision):
retrieval recall at 5 of 0.9767 on 43 questions
([eval_result.json](../../research/memory/eval_result.json)); the verifier makes 0 false accepts in 69
and 0 false rejects in 77 on the golden set, and 0 in 29 and 0 in 26 on a held-out set labelled before
its fixes, with Wilson upper bounds of 0.117 and 0.129 on the held-out
([verifier_golden_result.json](../../research/agents/evals/verifier_golden_result.json)); the
injection pattern flag catches only 16 of 61 attacks, and the tool allowlist refused all 1,191
off-list calls ([injection_result.json](../../research/agents/evals/injection_result.json)). Nothing
measures a real model's behaviour; AI_STACK.md "What is not there" lists the gaps.
