# v1.17.1 release notes (2026-10-17)

## Theme: negative results, and the release workflow fixed

v1.17.1 is a patch release after v1.17.0. It adds no new strategy. It records what the two
real-book studies found, adds data, and fixes the release workflow.

## What shipped

- **Release workflow fix (#211).** In v1.17.0 the release workflow's `manifest` job failed at its
  first step (`cyclonedx-py requirements -i <lock>`: `-i` is `--index-url` in cyclonedx-bom 7.x), so
  v1.17.0 has **no `release-manifest.json`, no Python lock-file SBOMs and no digest-pinned
  Kubernetes manifests** (its three images were built, pushed and attested). The lock file is now
  passed positionally. **v1.17.1 is the first release to carry all three.**
- **`sor_sweep` route** (opt-in, default unchanged): `ExecutionReplay(router_sweep=True)` ranks both
  books' depth all-in net of our overlay and sends one IOC LIMIT per venue.
- **`process-iex-day --keep-normalized`** (default) keeps the IEX day's normalized events and
  Parquet, hashed into `KEEP.json`, so B8 can replay both venues.
- **IEX overlap days.** Five of the nine approved days are recorded on main: 2025-11-28, 12-08,
  12-09, 12-10 and 2026-05-15, each with the TOPS oracle at 0 mismatches on AAPL / MSFT / QQQ
  (`docs/research/IEX_OVERLAP_SET.md`). More rows land as the remaining days finish.
- **Docs.** B7 closure and B8 text in README, the site, ROADMAP, EXECUTION_QUALITY and SHOWCASE.
