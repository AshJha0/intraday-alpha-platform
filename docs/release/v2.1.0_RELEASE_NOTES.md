# v2.1.0 release notes: showcase and streamline

Written 2026-10-27. v2.1.0 adds **no research claim**. Every result keeps the evidence class it had at
v2.0.0; nothing on `main` is above *development-supported*, and no alpha is confirmed
([REPORT.md](../REPORT.md) section 2). The synthetic demos added here carry no class.

## Negative and limiting facts, first

- The free daily data route still fails DD1 (rejected) and daily families D1 to D4 stay
  data-ineligible. The D2 and D4 construction defects (D-106, D-107) are fixed, so the exploratory
  chain now covers D1 to D4; that rerun is labelled exploratory, data-ineligible
  ([evidence/DD1_2026_EXPLORATORY_RERUN_2026-10-27.md](evidence/DD1_2026_EXPLORATORY_RERUN_2026-10-27.md)).
- `tools/research/dd1_chain.py` changed by two lines for that fix. The v2.0.0 evidence manifest pins
  its hash and stays valid at the `v2.0.0` tag, which is what it records;
  `evidence_manifest.py check` run on `main` now reports that file as changed.
- The new C++ book and feature benchmark reports in-process numbers on shared CI hardware: not
  colocation, and no latency edge ([HOT_PATH.md](../HOT_PATH.md)).
- The live agent eval on the anthropic SDK 2.x is one run of 4 scenarios (all passed, USD 0.0060);
  it shows the upgrade works, not that the agents are good researchers.
