Model: IC of symbol i in session s = mu + c_s + e_is with Var(c_s + e_is) = sigma_1^2 and correlation rho across symbols (common market factor). The N-symbol pooled per-session series has sd sigma_N = sigma_ref * sqrt((rho + (1-rho)/N) / (rho + (1-rho)/3)), calibrated on the measured 3-symbol (AAPL, MSFT, QQQ) fold sd; the within-session HAC SE is rescaled the same way. mu (the pooled IC of the new universe) is set to the 3-symbol value; the dispersion table shows how far a single symbol can sit from it.
