## Flow (tools/release.py)
1. [ ] Merge the working branches into `release/v1.16.0` (one PR, merged by the owner).
2. [ ] Run `python tools/release.py prepare-regenerate --branch release/v1.16.0`.
       It resets `research/experiments.json` to origin/main, drops the 5 runner dirs, commits, pushes and
       dispatches `ci.yml -f regenerate=true -f regenerate_allow_rerun=true`.
       Push with an explicit remote and branch: `git push origin release/v1.16.0`.
3. [ ] Run `python tools/release.py apply-bundle --run-id <regenerate run id>`.
       It downloads `regenerated-artefacts` and, since #141, extracts with Python `tarfile`, skipping the
       CRLF-only `expected_features*`. Review the diff.
       Restore any experiment dirs that the regenerate does not recreate (`git checkout origin/main -- <dir>`).
       Commit, then `git push origin release/v1.16.0`.
4. [ ] The owner merges the release PR (merge commit).
5. [ ] Run `python tools/release.py publish --version 1.16.0`.
       It waits for main CI + CodeQL to be green, creates the annotated tag from the CHANGELOG, runs
       `gh release --verify-tag`, then release.yml (rerun it if verify-ci raced). The site then shows v1.16.0.

## After
