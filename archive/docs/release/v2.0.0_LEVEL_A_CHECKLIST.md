# v2.0.0 Level A acceptance checklist (draft, 2026-10-26)

**The plain idea.** Level A says the platform is built and tested to the plan's standard. It says nothing about
whether any strategy makes money. This list names each Level A condition, the command or CI job that shows it, and
whether that has been shown. A status of "unknown" means the proof has not been run for the release commit.

**The formal statement.** The Level A pass condition (plan
`IAP_v2.0_Unified_Programme_Plan_2026-10-24.md` section 9, all required): every stage-11 acceptance test green on the
pinned image; the H1-equivalence test green; conservation, refusal, leakage-canary and isolation tests green; registry
and evidence manifest complete; runbook executed by someone other than the author. Owner decision DR-19 sets v2.0 to
ship at Level A.

**A worked example.** Row A2 is shown by `python -m pytest -q python/tests/equivalence` on the release commit, and by
the `python` job of `ci.yml` on that commit. Until either has run on the commit to be tagged, its status is "unknown",
even though the same test was green on earlier commits.

Commands run from the repository root with the CI interpreter, `PYTHONPATH=python/src`.
